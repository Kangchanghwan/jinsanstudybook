10. 장애물 앞에서 멈추는 라인트레이서 (마퀸)

★★★ 초음파 센서 조건 우선순위 코드 합치기 함수

9번 라인트레이서에 7번의 초음파 센서를 더해, 선 위에 장애물이 있으면 멈추는 로봇

이 단계에서는 두 프로젝트를 합치면 무엇이 되는지 보고, 먼저 끝내 두어야 할 것을 확인합니다.

무엇을 만드나요?

9번 라인트레이서는 선만 보고 달립니다. 선 위에 책이 놓여 있어도 그대로 부딪혀요. 여기에 7번에서 쓴 초음파 센서를 더해, 앞에 장애물이 있으면 멈추고 치워지면 다시 선을 따라 달리는 로봇을 만듭니다. 실제 서빙 로봇이 사람 앞에서 잠깐 멈추는 것과 같아요.

새로 배우는 것은 조건의 우선순위입니다. 무한반복에서 "선이 어디 있나"보다 "앞에 장애물이 있나"를 먼저 물어야 합니다. 순서가 바뀌면 멈추지 못해요.

먼저 끝내 두세요

9번 라인트레이서선을 따라 달리는 코드가 완성되어 있어야 합니다. 그 프로젝트를 그대로 이어서 씁니다.
7번 3단계확장 sonar가 추가되어 있어야 ping 블록이 보입니다. 9번 프로젝트에 없다면 지금 추가하세요.
7번 코드 ①ping 블록으로 거리를 재는 방법을 기억해 두세요. trig P1 · echo P2 · unit cm.

생각해 보기

  • 선을 따라가는 중에 앞에 벽이 나타나면 무엇을 먼저 해야 할까?
  • "멈춘다"는 모터에 어떤 값을 주는 걸까?
  • 장애물이 치워진 뒤에는 어떻게 다시 달릴까?

준비물 (모둠당)

  • 9번에서 쓴 마퀸 + 검은 라인 트랙
  • HC-SR04 초음파 센서 (마퀸 앞쪽 소켓에 꽂기)
  • 장애물로 쓸 책이나 상자
  • 확장: DFRobot_MaqueenPlus_v20 + sonar

이 단계에서는 무한반복 안의 판단 순서를 정하고, 새로 만들 정지 함수를 설계합니다.

무한반복 한 바퀴에서 일어나는 일

  1. ① 거리 재기ping 블록으로 앞쪽 거리(cm)를 변수 거리에 저장
  2. ② 장애물 먼저 확인만약 거리 < 14 이면 → 함수호출 정지
  3. ③ 아니면 선 판단9번과 똑같이 센서 값 조합으로 라인위 · 왼쪽이탈 · 오른쪽이탈 · 경로이탈
  4. ④ 다시 처음으로장애물이 치워지면 ②가 거짓이 되어 자연스럽게 ③으로 돌아옴

②와 ③은 만약 ~ 이면 / 아니면 하나로 묶습니다. 장애물이 있을 때는 선 판단을 아예 하지 않는 것이 포인트예요. 그래서 "아니면" 안에 9번의 판단을 통째로 넣습니다.

새 함수: 정지

정지모든 모터 속도 0 · P8 0, P12 0 (헤드라이트 끄기)

9번의 함수 4개는 그대로 두고 정지만 하나 더 만듭니다. "동작은 함수에서" 규칙을 지키면 무한반복이 지저분해지지 않아요.

핀 배치

P1 / P2초음파 Trig / Echo (7번과 같음)
P13 / P14왼쪽 / 오른쪽 적외선 센서
P8 / P12헤드라이트 왼쪽 / 오른쪽
P15밑면 RGB LED (경광등)

이 단계에서는 9번 프로젝트에 정지 함수 + 거리 재기 + 만약/아니면 한 겹을 더해 완성합니다.

블록 코드 — 장애물 앞에서 정지

블록 코드보기 전용

이 화면은 보기 전용입니다. 9번 코드와 비교해 달라진 곳(정지 함수, 무한반복 맨 위의 ping, 바깥쪽 만약/아니면)만 찾아 추가하세요. 크게 보기가 편해요.

만드는 순서

  1. 9번 프로젝트 열기 + sonar 확장 추가 MakeCode 홈에서 9번 프로젝트를 열고, 고급 → 확장 → sonar를 추가합니다.
  2. 정지 함수 만들기 고급 → 함수 → 함수 만들기 → 이름 정지. 안에 모든 모터 속도 0, P8 · P12 디지털 값 출력 0.
  3. 무한반복 맨 위에 거리 재기 거리에 ping trig P1 echo P2 unit cm 저장을 (경광등 블록이 있다면 그 아래, 선 판단 만약 위에) 넣습니다. 변수 "거리"는 새로 만들어요.
  4. 바깥쪽 만약/아니면 씌우기 새 만약 거리 < 14 이면 / 아니면 블록을 놓고, 이면 안에 함수호출 정지, 아니면 안에는 9번의 선 판단 만약 덩어리를 통째로 끌어 넣습니다.
  5. 테스트 다운로드 → 선 위에서 출발 → 선 위에 책을 놓아 보세요. 멈췄다가, 책을 치우면 다시 달리면 성공!

블록 찾는 곳 — Sonar → ping | 변수 → "거리" 만들기 | 논리 → 만약~이면/아니면, 비교(<) | 고급 → 함수 → 함수 만들기, 함수호출 | MaqueenPlusV2&V3 → 모터 블록

내 코드 점검 체크리스트

  • ping 블록이 선 판단 위에 있나요? (거리를 먼저 재야 비교할 수 있어요)
  • 바깥쪽 만약의 조건이 거리 < 14인가요?
  • 9번의 만약 4개가 모두 아니면 안에 들어갔나요?
  • 정지 함수 안 모터 속도가 0인가요?

막힐 때

장애물이 있어도 안 멈춰요.
ping 블록의 P1 / P2 · unit cm를 확인하고, 초음파 센서가 앞을 향하는지 보세요. 조건값 14를 20으로 키워 보세요.

멈춘 뒤 다시 안 달려요.
정지 함수 안에 "일시중지"나 "무한반복"이 들어가 있지 않은지 확인하세요. 정지는 속도 0만 주고 바로 끝나야 해요.

선을 따라가다 자꾸 멈춰요.
트랙 옆에 벽이나 책상 다리가 가까이 있지 않나요? 조건값 14를 8 정도로 낮추세요.

ping 블록이 없어요.
sonar 확장을 이 프로젝트에도 추가해야 합니다. 7번 3단계 참고.

완성했다면 멈추는 대신 다른 일을 시켜 보세요. 아래에 심화 예시 코드가 하나 더 있어요.

도전 과제

경적 울리기정지 함수 안에 음악 → "음 재생"을 넣어 장애물 앞에서 소리 내기.
거리 표시정지 함수에서 "숫자 출력 거리"로 장애물까지의 거리를 화면에 보여 주기.
기다렸다 후진정지 대신 1초 기다린 뒤 잠깐 후진해서 거리를 벌려 보기.
선을 놓치면 자율주행경로이탈 대신 7번의 자율주행 함수를 부르면? → 아래 심화 예시

심화 예시 — 선을 놓치면 자율주행으로 바꾸기

두 센서가 모두 1(흰색)일 때 경로이탈 대신 자율주행_경찰차 함수를 부릅니다. 그러면 선을 놓친 마퀸이 7번처럼 벽을 피하며 돌아다녀요. 경로이탈 함수는 남아 있지만 쓰이지 않습니다.

블록 코드보기 전용

이 화면은 보기 전용입니다. 자율주행_경찰차 함수 안은 7번 코드 ②의 무한반복 내용과 같아요.

심화 예시 만드는 순서

  1. 자율주행_경찰차 함수 만들기 7번 코드 ②의 무한반복 안 내용(경광등 + ping + 만약 2개)을 그대로 함수 안에 넣습니다.
  2. 경로이탈 자리 바꾸기 P13 = 1 그리고 P14 = 1 조건 안의 "함수호출 경로이탈"을 "함수호출 자율주행_경찰차"로 바꿉니다.
  3. 테스트 트랙 끝에서 선이 끊기게 만들어 두고, 선을 놓친 뒤 벽을 피해 다니는지 보세요.
