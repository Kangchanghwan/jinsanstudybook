8. 빛을 따라오는 마퀸

★☆☆ 빛 센서 만약~아니면 센서값을 속도로

손전등을 비추면 밝을수록 빠르게 따라오고, 어두우면 멈추는 로봇

이 단계에서는 무엇을 만드는지 영상으로 보고, 준비물을 확인합니다.

무엇을 만드나요?

손전등을 비추면 따라오고, 어두우면 멈추는 로봇입니다. 센서를 따로 달지 않아도 됩니다. micro:bit의 5×5 LED 화면이 빛 센서 역할을 하기 때문입니다.

모터 속도 칸에 숫자 대신 빛 밝기 블록을 끼워 넣어 "밝을수록 빠르게" 만드는 것이 핵심입니다. 블록 수가 적어 7번보다 쉽지만, "센서값을 그대로 속도로 쓴다"는 새로운 생각이 들어 있어요.

먼저 볼까요? 손전등을 따라오는 마퀸

영상을 보며 생각해 보기

  • 마퀸은 무엇으로 빛을 느낄까? 센서가 어디에 붙어 있을까?
  • 손전등을 가까이 하면 빨라질까, 느려질까?

준비물 (모둠당)

  • micro:bit + 마퀸(Maqueen) 본체, AA 건전지 3개
  • micro USB 케이블, 인터넷이 되는 PC
  • 손전등 또는 스마트폰 플래시
  • 확장: DFRobot_MaqueenPlus_v20 (추가 방법은 7번 프로젝트 3단계 참고)

이 단계에서는 빛 센서가 어디에 있고 어떤 값을 주는지 직접 재 봅니다.

빛 센서는 어디에 있을까?

micro:bit의 5×5 LED는 빛을 내기도 하고 빛을 받아들이기도 합니다. 주변 밝기를 0(어둠) ~ 255(아주 밝음) 값으로 알려 줍니다.

  • 블록: 입력 → 빛 밝기 (확장 설치 필요 없음)
  • 손전등을 화면에 비추면 값이 커지고, 손으로 가리면 작아져요.
  • 값이 곧 속도가 됩니다. 마퀸 모터 속도도 0~255 범위라서 딱 맞아요.

워밍업: 교실 밝기 재 보기

  1. 무한반복 안에 숫자 출력 [빛 밝기] 기본 → 숫자 출력, 입력 → 빛 밝기.
  2. 다운로드해서 확인 교실에서 보통 얼마가 나오나요? 손전등을 비추면? 손으로 가리면?
  3. 기준값 정하기 "교실 값보다 크고 손전등 값보다 작은 숫자"를 기준값으로 씁니다. 보통 190 정도.

이 단계에서는 블록 코드를 보고 만약~아니면 하나로 완성합니다. 블록은 5개뿐이에요.

블록 코드

블록 코드보기 전용

이 화면은 보기 전용입니다. 블록을 보고 내 프로젝트에서 직접 조립하세요. 속도 칸에 빛 밝기 블록이 들어간 것을 잘 보세요.

만드는 순서

  1. 만약 ~ 이면 / 아니면 무한반복 안에 만약 블록을 넣고 (+) 버튼을 눌러 아니면을 추가합니다.
  2. 밝으면 빛의 세기만큼 전진 조건에 빛 밝기 > 190. 안에는 모든 모터 방향 전진 속도 [빛 밝기]. 속도 칸의 숫자를 빼고 보라색 빛 밝기 블록을 끼워 넣는 것이 포인트! 값이 200이면 속도 200, 250이면 속도 250 → 밝을수록 빨라요.
  3. 어두우면 정지 아니면에는 모든 모터 방향 전진 속도 0. 190 이하일 때 실행됩니다.
  4. 테스트 다운로드 → 마퀸 전원 ON → 조명을 조금 어둡게 한 뒤 손전등을 micro:bit 화면에 비추며 앞으로 이동. 빛을 끄면 멈추면 성공!

블록 찾는 곳 — 논리 → 만약~이면/아니면, 비교(>) | 입력 → 빛 밝기 | MaqueenPlusV2&V3 → 모터 블록

이 단계에서는 마퀸에 올려 동작을 확인하고, 잘 안 될 때 고칠 곳을 찾습니다.
