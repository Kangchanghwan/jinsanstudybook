9. 라인트레이서 (마퀸)

★★★ 적외선 센서 그리고(and) 함수 조건 중첩

적외선 센서 2개로 검은 선을 찾아 스스로 달리고, 헤드라이트·경광등을 켜는 로봇

이 단계에서는 무엇을 만드는지 영상으로 보고, 준비물과 트랙을 확인합니다.

무엇을 만드나요?

바닥의 검은 선을 밑면 적외선 센서 2개로 찾아가며 스스로 달리는 로봇입니다. 공장의 운반 로봇, 식당 서빙 로봇의 기본 원리예요.

왼쪽·오른쪽 센서 값의 조합으로 4가지 상황을 판단하고, 상황별 동작을 함수로 나누어 두는 것이 핵심입니다. 판단은 무한반복에서, 동작은 함수에서! 앞쪽 헤드라이트는 "지금 어느 함수가 실행 중인지" 보여 주는 표시등이고, 밑면 경광등은 7번에서 배운 것을 다시 씁니다.

먼저 볼까요? 검은 선을 따라 달리는 마퀸

영상을 보며 생각해 보기

  • 마퀸은 선이 어느 쪽에 있는지 어떻게 알까?
  • 선에서 벗어나면 어느 바퀴를 돌려야 돌아올까?
  • 선을 완전히 놓치면 어떻게 해야 할까?

준비물 (모둠당)

  • micro:bit + 마퀸 본체, AA 건전지 3개, USB 케이블
  • 검은색 라인 트랙: 흰 전지 + 검정 절연 테이프(폭 약 2cm)
  • 확장: DFRobot_MaqueenPlus_v20 (추가 방법은 7번 프로젝트 3단계 참고)

이 단계에서는 적외선 센서가 흰색과 검은색을 구별하는 방법과 핀 번호를 알아 둡니다.

적외선 센서: 흰 바닥은 1, 검은 선은 0

센서 하나에 눈이 두 개입니다. 발광부가 눈에 안 보이는 적외선을 바닥으로 쏘고, 수광부가 튕겨 온 빛을 받습니다.

  • 흰 바닥: 빛이 반사되어 돌아옴 → 값 1
  • 검은 선: 빛을 흡수해 못 받음 → 값 0
  • 그래서 값이 0이면 "지금 검은 선 위!", 1이면 "흰 바닥 위!"

핀 배치

P13왼쪽 적외선 센서 (디지털 입력)
P14오른쪽 적외선 센서 (디지털 입력)
P8 / P12앞쪽 헤드라이트 LED 왼쪽 / 오른쪽 (디지털 출력 1 = 켜기)
P15밑면 RGB LED 4개 (경광등)

워밍업: 센서 값 확인하기

  1. 숫자 출력 [P13의 디지털 입력 값] 고급 → 핀 → "P0의 디지털 입력 값"을 P13으로 바꿔 무한반복에 넣습니다.
  2. 흰 종이와 검정 테이프 위에 올려 보기 1 ↔ 0으로 바뀌면 센서가 잘 동작하는 것. P14도 같은 방법으로 확인!

이 단계에서는 코드를 만들기 전에 센서 값 조합 → 상황 → 동작 → 함수 이름을 표로 정리합니다. 이 표가 곧 코드의 설계도예요.

센서 값 조합으로 4가지 상황 판단하기

왼쪽 센서 (P13)오른쪽 센서 (P14)마퀸의 상황해야 할 동작함수 이름
0 (검정)0 (검정)선 위에 잘 있음직진 + 헤드라이트 둘 다 켜기라인위
1 (흰색)0 (검정)왼쪽으로 벗어남우회전 (왼쪽 바퀴만 돌리기)왼쪽이탈
0 (검정)1 (흰색)오른쪽으로 벗어남좌회전 (오른쪽 바퀴만 돌리기)오른쪽이탈
1 (흰색)1 (흰색)선을 완전히 놓침천천히 돌며 선 찾기 + 라이트 끄기경로이탈

"P13의 디지털 입력 값 = 0 그리고 P14의 디지털 입력 값 = 0"처럼 그리고로 묶으면 두 조건이 모두 참일 때만 실행됩니다.

함수 안에 넣을 것

라인위모든 모터 전진 20 · P8, P12에 1 출력 (라이트 둘 다 켬)
왼쪽이탈왼쪽 20, 오른쪽 0 (우회전) · P8 0, P12 1
오른쪽이탈왼쪽 0, 오른쪽 20 (좌회전) · P8 1, P12 0
경로이탈왼쪽 16, 오른쪽 20 (크게 돌며 선 찾기) · P8 0, P12 0

헤드라이트는 "지금 어느 함수가 실행 중인지" 보여 주는 표시등입니다. 도는 쪽 라이트가 켜져요.

왜 함수로 나눌까?

  • 무한반복 안에는 판단(만약)만 남아 한눈에 읽혀요.
  • 동작을 고칠 때 함수 안 숫자만 바꾸면 돼요.
  • 10번 프로젝트에서 정지 함수를 하나 더 붙이기만 하면 됩니다.

이 단계에서는 블록 코드를 보고 함수 4개 → 무한반복 판단 → 경광등 순서로 조립합니다.

블록 코드

블록 코드보기 전용

이 화면은 보기 전용입니다. 함수 4개와 무한반복이 나란히 있어 넓으니 크게 보기를 누르고, 3단계 표와 비교하며 조립하세요.

만드는 순서

  1. 함수 4개 만들기 고급 → 함수 → 함수 만들기로 라인위 · 왼쪽이탈 · 오른쪽이탈 · 경로이탈을 만듭니다. 안은 3단계의 "함수 안에 넣을 것"대로 채워요.
  2. 무한반복에서 판단하기 만약 ~ 이면 / 아니면을 넣고, 아니면 안에 만약 3개를 더 넣습니다 ((+) 버튼). 조건은 표의 순서대로 P13 = 0 그리고 P14 = 0 → 함수호출 라인위 … 경로이탈까지.
  3. 경광등 (선택) 무한반복 맨 위의 RGB LED P15 0~3번 빨강·파랑 4개는 7번 코드 ②에서 배운 경광등입니다. 없어도 라인트레이서는 똑같이 달립니다.
  4. 트랙 만들고 달리기 흰 전지에 검정 절연 테이프로 둥근 코스를 붙입니다. 급한 커브는 피하고, 마퀸을 선 위에 올려 출발!

블록 찾는 곳 — 고급 → 핀 → "P0의 디지털 입력 값"을 P13 / P14로 바꾸기, "디지털 값 출력" | 논리 → 그리고, 비교(=) | 고급 → 함수 → 함수 만들기, 함수호출 | MaqueenPlusV2&V3 → 모터 블록

내 코드 점검 체크리스트

  • 함수 이름 4개가 표와 같은가요?
  • 만약 4개의 조건이 모두 그리고로 두 센서를 묶었나요?
  • P13 = 0, P14 = 0 조합이 라인위로 가나요?
  • 각 함수 안에 모터 블록 + 헤드라이트 출력 2개가 있나요?

막힐 때

선을 자꾸 벗어나요.
속도 20을 더 낮추거나 커브를 더 완만하게. 경로이탈의 16/20 차이를 키우면 더 작게 돌아요.

반대로 돌아요.
왼쪽이탈/오른쪽이탈 함수의 바퀴 속도(20/0)가 서로 바뀌지 않았는지 확인하세요.

계속 직진만 해요.
2단계 워밍업처럼 "숫자 출력 P13의 디지털 입력 값"으로 센서 값이 바뀌는지 확인하세요. 바닥이 너무 반짝이지 않는지도요.

완성했다면 속도와 함수 안 숫자를 바꿔 보세요. 초음파 센서와 합치는 것은 다음 프로젝트에서!
