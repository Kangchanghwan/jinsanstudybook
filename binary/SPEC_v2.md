# 이진수 챌린지 v2 변경 명세

## 1. 선생님 설정 (Google 시트 `settings` 탭)
- 스프레드시트에 `settings` 탭 추가. 형태 (A열 키, B열 값, C열 설명):
  | 키 | 값 | 설명 |
  |---|---|---|
  | stage1_count | 8 | 스테이지1 전구 켜기 문제 수 (1~15) |
  | stage2_count | 8 | 스테이지2 카드 뒤집기 문제 수 (1~20) |
  | stage3_count | 5 | 스테이지3 나눗셈 사다리 문제 수 (1~11) |
  | stage4_seconds | 60 | 스테이지4 타임어택 제한 시간(초) (20~180) |
  - 1행은 헤더(`항목 | 값 | 설명`). 시트에서 보기 쉽게 A열 키 옆 C열에 한국어 설명.
- Code.gs:
  - `setup()`이 `settings` 탭이 없으면 위 기본값으로 생성 (records 기존 데이터는 절대 건드리지 않음).
  - `doGet(action=config)` → `{ok:true, config:{stage1_count, stage2_count, stage3_count, stage4_seconds}}`. 값은 서버에서 범위 클램프, 숫자 아니면 기본값. CacheService 10초 캐시.
  - `doGet(action=ranking)` 응답에 `config`도 함께 실어 보내 (요청 수 절약).
  - doPost 점수 검증 상한을 설정에 맞게 넉넉히 (예: 0~50000).
- game.js:
  - 시작 시와 스테이지 맵 진입 시 config를 받아 `CFG.stage` 값 갱신 (실패하면 기본값 8/8/5/60 유지, 화면에 에러 노출하지 않음). 스테이지 시작 직전에 가장 최근 값 사용.
  - Stage1: targets = shuffle(1~15).slice(0,N). Stage2: N>15이면 중복 허용(연속 중복은 피함), 유형 A/B 반반(홀수면 A 하나 더). Stage3: shuffle(5~15).slice(0,N) (N ≤ 11).
  - 진행 표시(문제 x / N), 안내 카드의 "8문제" 등 문구, 스테이지 카드의 "타임어택 60초" 이름, 타이머 초기값이 모두 설정값을 따르도록.
  - 시간 보너스 기준시간을 문제 수에 비례: BASE_PER_Q = {1: 7.5, 2: 10, 3: 30}초 x N.
  - Stage4 별 기준을 시간에 비례: 3별 = 1500 x (sec/60), 2별 = 800 x (sec/60), 반올림.
- 결과 화면/기록에는 변경 없음 (records 컬럼 그대로).

## 2. 전 스테이지 처음부터 개방
- `unlocked()`가 항상 true. 잠김 표시·자물쇠 아이콘 제거.
- "여기 눌러요!" 추천 표시는 아직 클리어하지 않은 가장 앞 스테이지에 유지(안내 목적).

## 3. 준실시간 랭킹
### 3-1. 게임 중 미니 랭킹 (학생 화면)
- 스테이지 맵과 모든 스테이지 플레이 화면 오른쪽 아래(또는 기존 레이아웃을 가리지 않는 위치)에 작은 패널: "우리 반 실시간 순위" TOP 5 + 내 순위 한 줄. 반투명이 아닌 B안 스타일 카드(굵은 외곽선)로, 문제 풀이 영역을 절대 가리지 않게 배치. 1920x1080 무대 안에서 겹침 없이 넣을 공간이 없으면 상단 정보 바에 "내 순위 3위 (▲1)" 형태의 배지로 대체.
- 5초 간격 폴링 + 0~1.5초 랜덤 지터. 탭이 백그라운드(document.hidden)면 중단. 요청이 진행 중이면 다음 요청 건너뜀. 응답 실패 시 다음 주기에 재시도(백오프 최대 20초).
- 내 순위가 오르면 초록 "▲n" 애니메이션 + 짧은 효과음, 내려가면 빨강 "▼n" (효과음 없음). 다른 학생이 내 위로 올라오면 "OO이(가) 추월!" 토스트 1.5초 (과하지 않게, 같은 학생 연속 토스트 10초 제한).
- 결과 화면에서 기록 전송 직후에는 즉시 한 번 새로고침.
- 기존 랭킹 화면도 30초 → 5초 폴링으로 변경, 순위 변동 애니메이션 적용.

### 3-2. 실시간 랭킹 보드 (선생님 프로젝터용)
- 새 페이지 `binary/board.html` (같은 style.css/config.js 재사용 가능, 별도 board.js). URL 파라미터 `?cls=3`이면 해당 반, 없으면 반 선택 버튼(1~CLASS_COUNT) 화면.
- 1920x1080 무대 scale. 큰 제목 "N반 실시간 랭킹", 현재 시각, 참여 인원.
- 왼쪽(넓게): 반 TOP 10. 순위 변동 시 행이 위/아래로 부드럽게 이동(FLIP 애니메이션), 점수는 카운트업, 새로 순위권 진입/추월 시 행 반짝임. 1~3위 메달.
- 오른쪽: 반 대항전 막대(1~10반 평균), 우리 반 강조.
- 하단 티커: 최근 기록 5건 "3반 12번 홍길동 STAGE 4 1,250점" (서버가 최근 기록을 내려줘야 함: ranking 응답에 `recent:[{cls,num,name,stage,score,time}]` 최근 8건 추가, 학년 전체 기준. 보드에서는 선택 반 우선 표시).
- 3초 폴링 (보드는 1대뿐이라 OK), document.hidden이면 중단.
- 전체화면 버튼(Fullscreen API).
- 게임 index 화면 어딘가에서 학생이 보드를 쉽게 열 필요는 없음. 대신 스테이지 맵의 "반 랭킹 보기" 화면 구석에 작은 "선생님용 보드" 링크 정도는 허용.
- 허브/게임 어디에도 이모지 금지, 외부 이미지 금지.

## 4. 서버 부하 대비 (Code.gs)
- ranking 계산 결과 캐시는 학년 단위 5초로 단축 (실시간성), 단 캐시 미스 시 동시 계산 폭주 방지를 위해 `LockService.getScriptLock().tryLock(3000)`으로 한 번만 계산하고 나머지는 직전 캐시(별도 키, 60초 보관 stale 캐시) 반환.
- 기록 POST 시 학년 랭킹 캐시 무효화(삭제) → 다음 폴링에 바로 반영.
- 응답 JSON 최소화.
